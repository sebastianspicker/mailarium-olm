# Web interfaces

Mailarium has two unrelated web-facing surfaces:

- a trusted-local Streamlit application over a real local archive; and
- a dependency-free static demonstration built only from synthetic data.

The static demo is not a deployment of the Streamlit application and must
never be described as connected to Mailarium runtime state.

## Trusted-local Streamlit application

Streamlit does not load `.env` itself. Start the application from the
repository root with the runtime paths exported or supplied in the launch
environment:

```bash
VECTOR_INDEX_PATH=private/runtime/current/vector-index \
SQLITE_PATH=private/runtime/current/email_metadata.db \
python -m streamlit run mailarium/web_app.py --server.address 127.0.0.1
```

`mailarium/web_app.py` is a thin launcher for `mailarium/interfaces/web/app.py`,
which validates optional path overrides, obtains one cached
`ApplicationRuntime` for the path pair, and passes runtime-owned services to
the web adapters. Pages do not open their own archive databases, search
engines, or mailbox services. Call
`mailarium.web_app.invalidate_runtime_cache()` when a code path must close
and replace cached runtimes.

The navigation destinations are:

| Page | Purpose |
| --- | --- |
| Search | Enter an investigation question with archive filters and retrieval options. |
| Inspect | Read candidate messages and full canonical sources, inspect provenance, follow threads, and download sources or results. |
| Export | Preview evidence selected by category and minimum relevance, then prepare an HTML report or CSV. |
| Overview | Display archive-level counts and derived analytics. |
| People | Browse extracted entities, which remain review aids rather than source facts. |
| Connections | Inspect relationships derived from retained correspondence. |
| Evidence | Review and manage local evidence collections. |
| Mailbox | Inspect configured EWS state and proposal-gated workflows. |

The primary task navigation follows Search, Inspect, Evidence, and Export.
Overview, People, Connections, Mailbox, runtime paths, and theme selection remain
available under Sources & tools. Inspect places candidate messages beside the
full canonical source; provenance and downloads expand below it. Search mode,
applied filters, scope, sort order, attachments, and result counts remain visible.
The selected source body is never replaced by a derived summary.

Capture finding opens a source-linked evidence draft with a required quote,
analyst summary, category, relevance, and optional notes. Quote matching uses the
archive normalization rules; a text match does not establish factual truth.
Unmatched quotes can still be saved with their verification state. Repeated
rerenders of a saved draft do not create duplicate evidence.

Export selects across saved archive evidence, independently of the search filters.
A preview shows the selected findings before generation. HTML includes analyst
summaries and source context; CSV contains structured evidence fields. Browser
downloads are the default. Optional local output validates the configured runtime
roots and rejects existing files. Success text distinguishes a prepared download
from an actual local write. Changing runtime paths clears archive-specific
search, draft, and export session state.

### Interface invariants

- Show source content beside derived ranks, entities, relationships, and
  provenance.
- Keep visible keyboard focus and readable contrast.
- Preserve operation at narrow viewport widths; multi-column content must
  collapse without horizontal clipping.
- Respect reduced-motion preferences.
- Provide explicit empty, warning, and error states.
- Validate runtime paths before opening application services.
- Keep destructive or remote mailbox actions behind the same process, account,
  proposal, and confirmation gates as the CLI and MCP interfaces.
- Communicate status in text as well as color.

The shared theme is generated by
`mailarium/interfaces/web/styles.py`. It provides day and night
themes with ink navy, silver accents, restrained ring geometry,
editorial serif headings, and native accessible controls. Rendering helpers live under
`mailarium/interfaces/web/`; `.streamlit/config.toml` supplies Streamlit
defaults. Style changes must not weaken the interaction and trust invariants
above.

Run the existing source smoke after web changes:

```bash
uv run python scripts/smoke/streamlit.py
```

This AppTest executes the application body and checks the initial surface. It
does not replace manual browser, responsive, keyboard, or assistive-technology
review.

## Static synthetic demonstration

`demo/` is a standalone HTML, CSS, and JavaScript representation of the
interface. It contains synthetic correspondence and has no network requests,
mailbox, archive, credentials, runtime paths, or dependency on the Python
package.

Preview it locally:

```bash
python3 -m http.server --directory demo 8000
```

Then open <http://localhost:8000>. Verify its privacy and interaction markers
with:

```bash
python3 scripts/smoke/pages_demo.py
```

The Pages workflow publishes only `demo/` after that static check. A
successful local check does not prove that GitHub Pages is configured or that a
remote deployment completed.
