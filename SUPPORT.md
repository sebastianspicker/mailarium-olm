# Support

Mailarium is alpha software maintained on a best-effort basis.

- Setup, usage, and troubleshooting: [`docs/README.md`](docs/README.md)
- Questions not answered by the docs: use the GitHub usage-question form with
  a synthetic scenario and sanitized diagnostics
- Reproducible defects: use the GitHub bug-report form with synthetic data
- Feature proposals: use the GitHub feature-request form
- Security issues: follow [`SECURITY.md`](SECURITY.md) and report privately

Public support requests must not contain real mailbox content, personal
identifiers, private local paths, databases, exports, or screenshots from a live
archive. Reduce the problem to a synthetic reproduction and include sanitized
version information and diagnostics.

The Streamlit UI is intended for a trusted local operator. Running Streamlit or
MCP on a shared or public network requires deployment controls outside this
project's current alpha support boundary.
